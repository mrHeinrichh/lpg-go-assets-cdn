# LPG GO Assets CDN

Public runtime assets for the LPG GO mobile app.

CDN base:

```text
https://cdn.jsdelivr.net/gh/mrHeinrichh/lpg-go-assets-cdn@main/
```

Files keep the same relative paths used by the app, for example:

```text
assets/images/logo_main.png
assets/sounds/oing_horn.mp3
config/refund-policy.json
```
